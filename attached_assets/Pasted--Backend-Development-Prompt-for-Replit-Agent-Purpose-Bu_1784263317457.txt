# Backend Development Prompt for Replit Agent

## Purpose

Build a **production-ready FastAPI backend (APIs only)** for a **Garage Management Mobile Application**.

The mobile application frontend already exists in another project. Your responsibility is to build only the backend REST APIs.

Do **not** build any frontend.

---

# Tech Stack

Use the following technologies:

* Python 3.12+
* FastAPI
* PostgreSQL
* SQLAlchemy 2.0 (Async)
* asyncpg
* Alembic (Database Migrations)
* Pydantic v2
* JWT Authentication
* Uvicorn
* Python-dotenv
* Loguru
* Pytest
* Docker & Docker Compose
* Swagger / OpenAPI

Use **async/await throughout the project**.

---

# Authentication

Implement OTP Authentication.

After OTP verification generate JWT Access Token.

Protected APIs must use JWT.

### APIs

POST /api/v1/auth/sign-up

POST /api/v1/auth/sign-in

POST /api/v1/auth/send-otp

POST /api/v1/auth/verify-otp

POST /api/v1/auth/logout

* WAITING_FOR_PARTS
* QUALITY_CHECK
* COMPLETED
* CANCELLED

* Pagination
* Search
* Sorting
* Filtering
* Date Range

PUT /api/v1/jobs/{job_id}

PATCH /api/v1/jobs/{job_id}/status

PATCH /api/v1/jobs/{job_id}/complete

DELETE /api/v1/jobs/{job_id}
