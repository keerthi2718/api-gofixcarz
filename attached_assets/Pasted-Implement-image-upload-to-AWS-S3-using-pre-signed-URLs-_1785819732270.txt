Implement image upload to AWS S3 using pre-signed URLs.

Tech Stack:
- Expo React Native
- TypeScript
- FastAPI Backend
- AWS S3

Requirements:

1. Allow the user to:
   - Pick an image from the gallery.
   - Capture an image using the camera (if supported).
   - Preview the selected image before uploading.

2. Validate:
   - Accept only JPEG, JPG, PNG, or WebP.
   - Maximum file size: 5 MB.
   - Show appropriate validation messages.

3. Upload Flow:
   - Call the FastAPI endpoint:

     POST /images/upload-url

   Send:

   {
       "file_name": "<original_file_name>",
       "content_type": "<mime_type>"
   }

   Include the JWT access token in the Authorization header.

4. The backend returns:

   {
       "upload_url": "...",
       "object_key": "users/{userId}/profile.jpg"
   }

5. Upload the selected image directly to AWS S3 using the returned upload_url with an HTTP PUT request.

   Requirements:
   - Upload only the binary image data.
   - Set the correct Content-Type header.
   - Do NOT send the JWT token while uploading to S3.
   - Do NOT use AWS SDK or AWS credentials in the frontend.
   - Do NOT hardcode bucket names or AWS keys.

6. After a successful upload, call:

   POST /users/profile-image

   Body:

   {
       "object_key": "users/{userId}/profile.jpg"
   }

   Include the JWT token.

7. Display upload progress.

8. Handle errors:
   - Network failure
   - Upload timeout
   - Invalid file
   - Upload cancellation
   - Backend errors

9. When displaying the profile image:
   - Call

     GET /users/profile-image

   - Backend returns:

     {
         "image_url": "..."
     }

   - Display the returned image_url using the Expo Image component.

10. Build reusable components and services:
    - ImagePickerService
    - S3UploadService
    - ApiService
    - UploadProgress component

11. Use async/await throughout.
12. Use TypeScript interfaces.
13. Keep the code modular and production-ready.
14. Follow Expo and React Native best practices.
15. The frontend must never have access to AWS credentials. All AWS authentication is handled by the FastAPI backend using pre-signed URLs.
