# Additional Requirements

## 1. Postman Support

Create and export a complete Postman collection.

Requirements:

* Include every API endpoint.
* Organize APIs into folders.
* Include sample request bodies and responses.
* Create a Postman Environment with:

  * base_url
  * access_token
* Automatically save the JWT token after login using a Postman test script.
* Export:

  * Garage_API.postman_collection.json
  * Garage.postman_environment.json

---

## 2. Database Accessibility

The PostgreSQL database must be accessible outside Replit.

I should be able to connect using:

* DBeaver
* pgAdmin

Provide the PostgreSQL connection details through environment variables.

I should be able to:

* View tables
* Insert records
* Update records
* Delete records
* Execute SQL queries
* Export tables
* Import CSV
* Create indexes
* View relationships

---

## 3. Database Backup & Restore

Provide scripts for database backup and restore.

Create:

```
scripts/
    backup_db.sh
    restore_db.sh
```

The backup script should generate a complete PostgreSQL SQL dump using `pg_dump`.

The restore script should restore the database using `psql` or `pg_restore`.

Also create a `backups/` directory.

Document the backup and restore process in the README.

---

## 4. Code Ownership

The generated project must be completely portable.

I should be able to:

* Download the complete source code at any time.
* Download the PostgreSQL database backup.
* Clone the repository and run it locally.
* Deploy it on another cloud provider without modifying the application code.
* Use my own PostgreSQL database instead of a Replit-managed database.

The project should not depend on proprietary Replit services.

---

## 5. Development Environment

Provide:

* `.env.example`
* Dockerfile
* docker-compose.yml
* Makefile (optional)

Running the project should require only:

```
docker compose up --build
```

or

```
uvicorn app.main:app --reload
```

---

## 6. API Standards

All APIs should return a consistent response format.

Example:

```json
{
  "success": true,
  "message": "Job created successfully",
  "data": {},
  "errors": [],
  "status_code": 201
}
```

Support:

* Pagination
* Filtering
* Sorting
* Search

Use query parameters consistently across all endpoints.
