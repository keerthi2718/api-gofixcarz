GoFixCarz API catalogue

67 documented operations. Generated from the running application contract.

Protected operations require Authorization: Bearer <access_token>. Garage-owner resources remain tenant-scoped. Platform-wide access is provided only by admin endpoints after JWT and account validation. Private administrator authentication URLs and credentials are deliberately excluded from this catalogue.

Admin integration: authenticate using the private contract, validate identity with GET /api/v1/admin/me, then fetch GET /api/v1/admin/menus. Do not show privileged menus when either returns 401 or 403. Admin access tokens last 15 minutes; refresh sessions last seven days. Billing issue review is read-only and does not repair historical records.
